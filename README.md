# گویا — تبدیل نوشتار به گفتار فارسی (نسخهٔ iOS)

این مخزن شامل **اپ بومی آیفون (Swift)** در پوشهٔ `ios/` و **وب‌اپ Next.js** (پوشهٔ `src/`) است.

- 📱 اپ آیفون: راهنمای کامل ساخت و نصب در [`IOS.md`](IOS.md)
- 🌐 وب‌اپ: همین‌جا (اجرا روی کامپیوتر یا نصب به‌عنوان PWA از Safari)

## اپ آیفون
کد بومی Swift در پوشهٔ `ios/` است. فایل `Gooya.ipa` با GitHub Actions روی مک ابری ساخته می‌شود (تب Actions ← Build iOS IPA ← Run workflow).
فایل ساخته‌شده **امضا ندارد** و باید با Sideloadly و Apple ID روی آیفون نصب شود؛ جزئیات و محدودیت‌ها (اعتبار ۷ روزه با Apple ID رایگان) در `IOS.md` آمده است.

## اجرای وب‌اپ روی کامپیوتر خودتان (بدون انتشار، بدون PostgreSQL)

۱. **Node.js** نسخهٔ LTS را از [nodejs.org](https://nodejs.org) نصب کنید (یک بار).
۲. در پوشهٔ پروژه:
   - **ویندوز:** روی `start-gooya.bat` دوبار کلیک کنید.
   - **مک/لینوکس:** `bash start-gooya.sh`
   - یا در ترمینال: `npm install` و سپس `npm run local`
۳. بار اول چند دقیقه طول می‌کشد (نصب و ساخت). بعد مرورگر خودکار روی `http://localhost:3000` باز می‌شود.

در ترمینال آدرسی مثل `http://192.168.1.10:3000` هم نشان داده می‌شود؛ آن را در **Safari آیفون** (متصل به همان Wi-Fi) باز کنید.
از دکمهٔ **Share** گزینهٔ **Add to Home Screen** را بزنید تا آیکون گویا روی صفحهٔ اصلی بنشیند.

- دیتابیس داخلی در پوشهٔ `data/` ذخیره می‌شود؛ متن‌ها و تنظیمات شما همان‌جا می‌مانند.
- صدای «نیورال» به اینترنت نیاز دارد؛ «صدای دستگاه» آفلاین کار می‌کند (اگر صدای فارسی روی گوشی نصب باشد).
- بعد از تغییر کد: `npm run local -- --build`

## اجرا با PostgreSQL (سرور)
متغیر `DATABASE_URL` را تنظیم کنید و `npm run build && npm start` را اجرا کنید. جدول‌ها خودکار ساخته می‌شوند.

## ساختار مخزن
```
ios/            اپ بومی آیفون (Swift / SwiftUI)
src/            وب‌اپ Next.js (صفحه‌ها، API، منطق اعراب‌گذاری و قطعه‌بندی)
public/         آیکون‌ها، manifest و service worker (PWA)
scripts/        اجرای محلی وب‌اپ
.github/        ساخت خودکار IPA
IOS.md          راهنمای اپ iOS
```
