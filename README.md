# گویا برای iOS (Swift)

بازنویسی بومی اپ اندروید «گویا» با SwiftUI. بدون وابستگی به سرور؛ مثل نسخهٔ اندروید.

## چه چیزهایی منتقل شده
- اعراب‌گذاری خودکار (واژه‌نامه + صرف فعل + پسوندها)
- قطعه‌بندی جمله‌به‌جمله با مکث‌های انسانی
- خواندن نمادها (٪ @ € + − × ÷ = و C++ و pro+ ...)
- هشت گوینده + صدای آنلاین نیورال (با توکن نسخهٔ ۲) و صدای خود دستگاه
- نوار قابل‌کشیدن، مکث/ادامه، و شروع از هر جمله با لمس آن

## هنوز منتقل نشده
تاریخچه، متن‌های ذخیره‌شده، واژه‌نامهٔ شخصی، خروجی MP3 و نوار علامت‌های اعراب.

## ساخت فایل نصبی (بدون مک)
1. این پوشه را به‌عنوان یک ریپوی جدید در گیت‌هاب بگذار.
2. Actions ← Build iOS IPA (unsigned) ← Run workflow.
3. بعد از اتمام، `Gooya-iOS` را دانلود کن و `Gooya.ipa` را با Sideloadly و Apple ID روی آیفون نصب کن (اعتبار ۷ روز).
4. artifact دوم (`Gooya-iOS-Simulator`) برای شبیه‌سازهای آنلاین مثل Appetize است.

## نکته
این کد روی مک و Xcode تست نشده است. اگر build خطا داد، متن خطا را بفرست.
